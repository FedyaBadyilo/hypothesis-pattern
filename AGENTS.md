# Agent context

This repository tests **LLM hypotheses** on document-centric technical tasks.

The main goal is not a mature production product on day one. The main goal is a **reproducible, debuggable, measurable research pipeline**: fast iteration, explicit artifacts, clear step boundaries, local debug runs you can repeat, and evaluation you can trust.

## Repository instructions

Use the repository rules when changing files or structure:

- `.cursor/rules/repository-layout.mdc` — where files belong, how to structure `infra/`, `research/`, `apps/`, and step workspaces.
- `.cursor/rules/research-pipeline-standards.mdc` — code style and engineering discipline for research pipeline logic.
